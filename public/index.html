Music library

Every track saved to a Navidrome library is logged with its tags, so Grabbit can tell you what you already have — and refuse to fetch the same song twice, even from another upload. A scan reads the libraries on disk and adds anything the log hasn't seen (files copied in by hand, or downloaded before the log existed).

Rules

Auto-apply settings when a link matches. The top rule wins. Matching is case-insensitive; wrap a pattern in /slashes/ for regex. An automatic rule starts shared links without opening the options sheet.

Cookies for private content

Scheduled retries

Clips whose file isn't published upstream yet (a freshly-uploaded post that 404s) are parked here and downloaded automatically once ready. A failed profile download queues them for you; you can also add one by hand.
